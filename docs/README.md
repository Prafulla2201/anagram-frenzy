# Anagram Game

Discover and explore the vast world of isomeric words by rearranging the letters of your favorite English words.

## 🏗️ Architecture & Tech Stack
- **Backend/Framework:** Python 3.9 with Flask
- **Database / Cache:** Redis
- **Auth & Security:** Basic Authentication

## 🚀 Quick Start
### Prerequisites
- Install Python 3.9
- Install Flask
- Install Redis

### Running with Docker Compose
